# Installation

## NPM Module

The package is available on npmjs.com.

:::tabs key:pkgmanager variant:code

== npm
```shell
npm install --save @pdfa-lab/core
```

== pnpm
```shell
pnpm add @pdfa-lab/core
```

== yarn
```shell
yarn add @pdfa-lab/core
```

== bun
```shell
bun add @pdfa-lab/core
```

## UMD Module (Browser)

You can also download `@pdfa-lab/core` as a UMD module from
[unpkg](https://unpkg.com/#/). The UMD builds have been compiled to ES5, so
they should work [in any modern browser](https://caniuse.com/#feat=es5). UMD 
builds are useful if you are not using a package manager or module bundler. 
For example, you can use them directly in the `<script>` tag of an HTML page.

The following builds are available:

* https://unpkg.com/@pdfa-lab/core/dist/index.browser.js
* https://unpkg.com/@pdfa-lab/core/dist/index.browser.min.js
